# 归墟之潮

基于 Godot 4.7 的仙侠动作 RPG 原型。当前版本使用程序化占位美术，核心系统已经打通。

## 已实现
- 45 度俯视 / 常规第三人称双视角，可在设置中切换，按 V 快捷切换
- 五行相生相克、天干地支与游戏内时辰演算
- 行囊、装备、使用/丢弃、敌人掉落
- 角色信息、境界突破、成就系统
- 实时战斗、普通攻击、四个五行技能、敌人 AI 与掉落
- 主菜单、继续修行、设置面板、成就面板
- 程序化占位场景与程序化音效

## 运行方式
1. 使用 Godot 4.7 打开项目目录。
2. 运行主场景 `res://scenes/main.tscn`。
3. 或在项目目录执行：`godot --path .`

## 操作
- WASD：移动（相对镜头方向）
- 鼠标左键：普通攻击
- Q / E 或按住鼠标右键 / 中键拖拽：旋转视角
- R：重置视角为当前模式预设
- 1-4：五行技能
- 5：厚土回春
- V：切换 45 度俯视 / 第三人称（各自保留镜头朝向）
- Tab / I：行囊
- C：角色
- K：成就
- Esc：设置
- 鼠标滚轮：缩放视角（拉近 / 拉远）

## 16:9 显示与手型光标（本轮）
- 分辨率选项统一为严格 16:9，高度由 `GameState.get_resolution_size()` 反推，下拉项标注比例：
  1280x720 / 1600x900 / 1920x1080 / 2560x1440 / 3840x2160（全部 16:9）
- 渲染直接输出到 OS 窗口（`content_scale_mode = DISABLED`）：**窗口/屏幕多大就填满多大**，

## 窗口填充修正
- 现象：从编辑器点运行、或手动拖动窗口大小时，画面不跟随窗口（四周/上下留黑边）
- 原因：上一轮为满足"分辨率全部 16:9"，`main.gd::_ensure_window_fill()` 在窗口比例不是严格 16:9 时
  会切到 `CONTENT_SCALE_MODE_VIEWPORT + ASPECT_KEEP`，按最大 16:9 画幅渲染并加黑边
  （例如窗口 1600x1000 → 画幅 1600x900，上下各 50px 黑边）
- 修正：改为固定 `CONTENT_SCALE_MODE_DISABLED`，视口始终等于窗口尺寸，内容实时填满窗口；
  16:9 只约束"分辨率选项"（1280x720 / 1600x900 / 1920x1080 / 2560x1440 / 3840x2160）
- 实测：窗口 2560x1440 → 视口 2560x1440；1600x1000 → 视口 1600x1000；1100x900 → 视口 1100x900；
  1920x1080 → 视口 1920x1080，全部 1:1 填满，无黑边
