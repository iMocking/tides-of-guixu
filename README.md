# 归墟之潮

基于 Godot 4.7 的仙侠动作 RPG 原型。当前版本使用程序化占位美术，核心系统已经打通。

## 已实现
- 45 度俯视 / 常规第三人称双视角，可在设置中切换，按 V 快捷切换
- 五行相生相克、天干地支与游戏内时辰演算
- 行囊、装备、使用/丢弃、敌人掉落
- 角色信息、境界突破、成就系统
- 实时战斗、普通攻击、四个五行技能、敌人 AI 与掉落
- 主菜单、继续修行、设置面板、成就面板
- 程序化占位场景与程序化音效
- 玩家角色使用**骨骼动画模型**（GLB，9 段动作：待机 / 跑步 / 跳跃 / 攻击 / 闪避 / 死亡 / 打坐等）
- 玩家角色时装：10 套时装、试衣镜预览、染色与光效、材料 / 境界解锁
- 大地图世界（**Terrain3D**）：高山、断崖、湖泊、密林、雪地、山洞秘境与古风建筑

## 运行方式
1. 使用 Godot 4.7 打开项目目录。
2. 运行主场景 `res://scenes/main.tscn`。
3. 或在项目目录执行：`godot --path .`

## 操作
- WASD：移动（相对镜头方向）
- Space：跳跃
- Shift：闪避
- 鼠标左键：普通攻击
- Q / E 或按住鼠标右键 / 中键拖拽：旋转视角
- R：重置视角为当前模式预设
- 1-4：五行技能
- 5：厚土回春
- V：切换 45 度俯视 / 第三人称（各自保留镜头朝向）
- Tab / I：行囊
- C：角色
- U：时装（试衣镜换装 / 染色 / 光效）
- K：成就
- Esc：游戏菜单（返回游戏 / 返回主界面 / 游戏设置 / 退出游戏）
- 鼠标滚轮：缩放视角（拉近 / 拉远）

## 窗口填充修正
- 现象：从编辑器点运行、或手动拖动窗口大小时，画面不跟随窗口（四周/上下留黑边）
- 原因：上一轮为满足"分辨率全部 16:9"，`main.gd::_ensure_window_fill()` 在窗口比例不是严格 16:9 时
  会切到 `CONTENT_SCALE_MODE_VIEWPORT + ASPECT_KEEP`，按最大 16:9 画幅渲染并加黑边
  （例如窗口 1600x1000 → 画幅 1600x900，上下各 50px 黑边）
- 修正：改为固定 `CONTENT_SCALE_MODE_DISABLED`，视口始终等于窗口尺寸，内容实时填满窗口；
  16:9 只约束"分辨率选项"（1280x720 / 1600x900 / 1920x1080 / 2560x1440 / 3840x2160）
- 实测：窗口 2560x1440 → 视口 2560x1440；1600x1000 → 视口 1600x1000；1100x900 → 视口 1100x900；
  1920x1080 → 视口 1920x1080，全部 1:1 填满，无黑边

## 大地图世界：Terrain3D + 地貌与地标（本轮）

### 接入 Terrain3D
- 新增 addon `addons/terrain_3d/`（Terrain3D **v1.0.2-stable** 官方发行包，含 Windows / Linux / macOS / Android / iOS / Web 二进制），
  并在 `project.godot` 的 `[editor_plugins]` 中启用
- 新增 `scripts/world/terrain3d_world.gd`（`Terrain3DWorld`）：运行时构建 Terrain3D 裁剪图（clipmap）
  - `region_size = 256`、`vertex_spacing = 2.0` → 单区 512 m；`REGION_RADIUS = 1` → 3×3 共 **9 区**、约 1536 m 见方
  - 地形数据**全部运行时生成、不落盘**（`data_directory = ""`）：每区按共享地形场采样 258×258 顶点
    （多一圈边界顶点用于精确求坡与生物群系抖动），打包成 `FORMAT_RF` 高度图与 packed 控制图后交给
    `Terrain3DData.import_images()`
  - 8 层地表（底色 / 草甸 / 林地 / 积雪 / 岩石 / 崖壁 / 沙洲 / 湖床）用 `NoiseTexture2D` 现场生成 albedo 与 normal，
    零外部贴图，符合项目「程序化占位美术」的约定
  - 碰撞用 Terrain3D 的 `Dynamic / Game` 模式（半径 190 m、分块 16 m），玩家脚下始终有碰撞
- **兜底**：`Terrain3DWorld.is_supported()` 检查 `ClassDB.class_exists("Terrain3D")`；插件缺失时自动回退到原有
  `TerrainGenerator`（流式低模分块）。两条后端共用同一套地形场，切换不会让世界在脚下变形

### 共享地形场 `TerrainData`
- `scripts/world/terrain_data.gd` 重写为「数据 + 纯函数」模块：噪声栈（丘陵 / 细节 / 山脊 / 湿度 / 崖面 / 湖岸 / 林地）、
  地貌参数、地标布局与生物群系表
- 地貌：
  - **苍梧山脉**（北侧）：椭圆掩膜 + 双层 ridged 噪声，峰值约 214 m
  - **断崖**：`terrace_height()` 把山体切成 6.5 m 一级的平台与陡坎，山前断崖带（z ≈ −150 ± 118 m）最强
  - **明镜湖**（东侧）：碗形下切到 −17 m，水面 −4 m
  - **幽冥林**（西侧）：`forest_mask()` = 核心衰减 × 斑块噪声 × 高程衰减
  - **云梦泽起始盆地**：半径 54 m 内压平到 5 m，让山门 / NPC / 任务内容保持可读
  - **地标平台**：每个建筑、洞口先在地形场里压出一块平台（`PADS`），建筑永远落在平地上
- 生物群系由「高度 + 坡度 + 林地密度」判定：湖底 / 汀洲 / 青芜原 / 幽冥林 / 石岭 / 断崖 / 雪巅
- 实测覆盖率：青芜原 66%、断崖 20%、幽冥林 6%、石岭 3%、雪巅 4%、湖 1.4%（其余为汀洲）

### 控制图打包（本轮最容易踩的坑）
- Terrain3D 把「base id(5b) + overlay id(5b) + blend(8b) + UV(7b) + hole/nav/auto」塞进一个 uint32，
  再借 `FORMAT_RF` 图片当整数通道用
- 这个 uint32 一旦被解释成 IEEE-754，就可能落进 subnormal / NaN 区间，而 Godot 的 float 通路会把它们吃掉
  （实测：NaN 位型经 `import_images()` 后变成 `0xFFFFFFFF`）
- 因此 **贴图 id 0 保留不用**：所有 base id 都 ≥ 1，指数位永不为 0，打包值恒为 normal float。
  测试对 8 层逐一断言「打包后的 float 是 normal 数」，这条约束也写进了 `TerrainData.TEXTURES` 的注释
- 生物群系交界用「取一个不同层的邻居 + 噪声抖动 blend」做斑驳过渡，而不是硬切

## 植被与岩石改为真实模型资源（本轮）
- 之前世界里的树、灌木、草、岩石都是**图元拼的占位几何**（圆柱树冠 + 球体灌木 + 方块石头）。
  本轮把它们全部删掉，换成从资源社区取得的**成品模型资源**，代码不再自己造植被。
- 素材来源：**Quaternius《Nature Pack》**（CC0，见 `CREDITS.md`），以自包含 `.glb` 形式引入
  `assets/models/vegetation/`，共 **74 个模型 / 约 4.3 MB**
  - `trees/` 36 个：Common / Birch / Pine / Willow 四族，各带 **Dead（枯木）** 与 **Snow（积雪）** 变体
  - `plants/` 15 个：灌木、浆果丛、蕨草、草本、草丛、野花
  - `rocks/` 17 个：普通石、长苔石、覆雪石
  - `wood/` 6 个：树桩与倒木，同样有长苔 / 覆雪版本
- 新增 `scripts/world/prop_models.gd`（`PropModels`）：把 `.glb` 场景扁平化成单个 `Mesh`
  - 合并场景内所有 `MeshInstance3D`，把局部变换烘进顶点，**每个原始面片保留一个 surface 与作者原本的材质**
  - 合并结果缓存复用；`MultiMeshInstance3D` 因此一个模型只占一个批次（平均 1～2 个 draw call）
  - **不改材质、不重绘颜色、不加顶点色**：树的绿、树皮的褐、雪的冷白、岩的灰都来自素材作者
  - 附带记录每个模型的自然高度与「原点离地高度」，实例按米数缩放并精确坐地
- `WorldFeatures` 的变化
  - 池表（pool）按「树种 / 灌木 / 草丛 / 野花 / 碎石 / 巨石 / 林下杂物」拆分，每条带一个目标高度 `h`（米）
  - **按海拔与坡度选种类**：雪线以上自动换成 `*_Snow` 变体，林下换成 `*_Moss` 变体，林外空地用普通岩石
  - 新增高山疏林散布：雪线以上按坡度筛选（坡太陡不长树），给雪山配上疏密有致的针叶林
  - 实例变化只靠**选种 + 缩放 + 朝向 + 轻微倾斜**；不再做逐实例染色（那需要改动作者材质）
  - 阴影只留给树与断崖巨石，灌木 / 草 / 碎石 / 倒木关掉投影，避免三角面数翻倍
  - 玄山洞的岩体也改用同一批巨石模型围合，不再用方块
- 实测（1440p，RTX 4060，D3D12）：世界生成 2.6 s；**83～85 FPS / p10 85**；
  92 个 props 批次、总绘制调用 873；三角面数由 3.0 M 升到 14.1 M（真实模型比图元重得多，换来的是细节）
- 测试新增：素材文件全部存在、合并后每个 surface 都带材质、**props 批次里不允许再有 `PrimitiveMesh`**、
  雪地植被数量下限
